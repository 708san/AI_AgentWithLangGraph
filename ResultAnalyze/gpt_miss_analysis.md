# GPTが正解疾患をTop 5に入れなかった理由の考察

## 結論

今回のGPT出力は「患者表現型から正解疾患を全く推定できない」ことを示す
というより、現在の入力形式とTop 5制約では、正解疾患よりも、表現型が似て
いて知名度の高い既知症候群を優先した結果と考えられる。

特に大きい要因は次の4点である。

1. GPTへの入力はHPOラベル、性別、発症時期だけで、遺伝子名、画像、論文、
   正解疾患の別名は与えていない。
2. 現行設定では `use_absentHPO=False` なので、入力TSVにある明示的な陰性所見
   はGPTプロンプトに含まれない。
3. KDM6Bでは発達遅滞・言語遅滞・低緊張・自閉傾向が中心で、疾患特異性が低い。
4. TRAF7では心奇形、眼瞼裂・眼間距離、短頸、骨格、聴覚、発達遅滞が複合するが、
   KAT6B、Kabuki、Aarskog-Scott、FLNAなど複数の既知症候群にも一致する。

## GPTに実際に与えられた情報

- モデル：`gpt-5-2`
- 入力：present HPOのラベル、性別、onset
- 入力していない情報：遺伝子名（TRAF7/KDM6B）、患者画像、Phenopacket ID、
  PMID、正解疾患名、遺伝形式
- 陰性所見：現行設定では入力していない
- 出力制約：最も可能性の高い疾患を5個

したがって、GPTは「TRAF7の患者」「KDM6Bの患者」としてではなく、遺伝子情報
なしの表現型鑑別として判断している。

## TRAF7群（OMIM:618164）

入力データ中のTRAF7 19症例で頻度の高いpresent HPOは、PDA 11/19、摂食障害
10/19、眼間開離 10/19、眼瞼裂狭小・眼瞼下垂関連所見、眼角贅皮、全般的発達遅滞
各9/19、筋緊張低下・低身長各8/19であった。今回の7症例にもこれらの所見は
部分的に存在するが、1症例にまとまって現れるとは限らない。

TRAF7群では、11706、11710、11715、11721のように正解疾患と共有する所見が
比較的多い症例でも、表現型が既知症候群の診断パターンに分解されている。これは
GPTが個々のHPOの単純一致をしているというより、学習済みの「有名な症候群の
まとまり」に対してパターン照合していることを示唆する。

## KDM6B群（OMIM:618505）

入力データ中のKDM6B 15症例では、言語発達遅滞が15/15、運動発達遅滞が14/15、
低緊張が9/15、自閉傾向と摂食障害が各8/15、関節過可動が6/15であった。
これらは正解疾患を支持するが、他の多くの神経発達症候群にも非常に一般的な所見
である。

### 症例別の解釈

| 症例 | 入力の特徴 | GPTが選んだ方向 |
|---|---|---|
| 12293 | presentが8個と少なく、言語・運動遅滞、低緊張、LGA、目立つ鼻、腎盂重複 | LGA・目立つ鼻からSimpson-Golabi-Behmel、Sotos、Weaver等の過成長症候群へ |
| 12300 | 巨頭、ID、自閉、低緊張、関節過可動、高口蓋、耳介・歯の特徴 | Au-Kline、KBG、Luscan-Lumish等。巨頭＋自閉＋発達遅滞の典型的候補へ |
| 12289 | LGA、長身、巨頭傾向、低緊張、自閉、睡眠障害、脳画像異常 | SETD2、CHD8、DNMT3Aなど過成長・自閉関連疾患へ |
| 12292 | IUGR、顔貌、頸椎癒合、合趾、ジストニア、構音障害 | Kleefstra、KBG、Coffin-Siris等の顔貌・骨格・発達障害へ |
| 12299 | presentが6個のみ。言語・運動遅滞、摂食障害、自閉、退行、cafe-au-lait | Legius、NF1、RASopathyへ。cafe-au-laitが強いアンカーになった可能性 |
| 12291 | presentが7個のみ。言語・運動・全般発達遅滞、自閉、眼瞼下垂 | Kleefstra、KAT6B、ADNPなど、顔貌・発達遅滞の既知疾患へ |

KDM6B群の問題は、正解疾患の共通所見が存在しないことではない。むしろ
「言語遅滞＋運動遅滞」はほぼ全例にある一方、疾患を絞る情報量が少ない。
KDM6Bの疾患名（データ上はNeurodevelopmental disorder with coarse facies and
mild distal skeletal abnormalities / NEDSST）がGPTの一般的な疾患想起に十分に
結びつかなければ、より頻出する過成長症候群、自閉症候群、クロマチン病へ流れる。

## 陰性所見を使わなかった影響

KDM6B群では、症例によっては10～20個のabsent HPOが入力TSVにある。しかし今回
のGPTプロンプトでは、現行パイプラインと合わせるため、これらを提示していない。
そのため、例えば「合指なし」「口蓋裂なし」「けいれんなし」「聴覚障害なし」など
の組み合わせを、候補疾患間の順位付けに利用できなかった。

これは単純に陰性所見を追加すれば正解になるという意味ではないが、少なくとも
今回の評価では、GPTに与えた情報は入力TSV全体より少ない。陰性所見を含める条件を
別実験にすれば、

- presentのみ
- present＋absent
- present＋疾患名の別名辞書
- present＋遺伝子候補を別工程で与える

を比較でき、GPTの知識不足と入力情報不足を分離できる。

## 総合評価

今回の15症例で正解が入らなかった主因は、次の順序で考えるのが妥当である。

1. 正解疾患が非常に稀で、疾患名・遺伝子と表現型の結びつきがGPTに強く形成されていない可能性。
2. 遺伝子名、画像、論文情報を除いたHPOラベルだけでは、TRAF7はKAT6B等、KDM6Bは過成長・自閉・クロマチン関連疾患と競合すること。
3. KDM6Bでは発達遅滞中心の非特異的入力、TRAF7では症例間の表現型ばらつきと多臓器所見の分散。
4. Top 5という出力制約により、低頻度・新しい疾患が候補から落ちやすいこと。

したがって、「GPTはこの表現型から正解疾患を推定できない」と断定するより、
「遺伝子情報なしのゼロショットTop 5では、正解疾患より既知の表現型近傍疾患を
優先した」と解釈するのが適切である。
